The Data Company · Design exploration · Color first

Palette atlas

Nine candidate palettes, each anchored to a real material or institution — owned color, not generated color. Every specimen renders the same header, headline, caption, and ledger line so the palette alone does the talking. The prior studies' palettes (ivory+green, phosphor-on-black, brass-on-black) are deliberately excluded.

How to read this: every specimen uses identical content — wordmark, headline, caption, CTA, one ledger row — so differences are purely color, type pairing, and finish. Names in the margin are the referent each palette is borrowed from. If two attract you, the move is usually a ground from one + an accent from another (e.g. Salmon's paper with Consular's vermillion).
